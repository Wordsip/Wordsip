Por & Para

Le piège classique de l'espagnol
UsoPorPara
causa / finalidadLo hice por amor.à cause de, motivé parLo hice para aprobar.dans le but de
duración / plazoViajé por dos semanas.durée (par)Lo necesito para el lunes.échéance
medio / destinatarioHablamos por teléfono.moyenEste regalo es para ti.destinataire
a través de / destinoCaminé por el parque.à travers un lieuSalgo para Madrid.vers une destination
precio / opiniónLo compré por 20 euros.échange, prixPara mí, es carísimo.point de vue
Astuce : pense « por » = cause, moyen, échange (regarde en arrière) — « para » = but, destinataire, destination (regarde en avant).
